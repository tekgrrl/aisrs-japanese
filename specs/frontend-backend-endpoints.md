## Backend endpoints with no known frontend caller

Found by comparing every `@Controller`/route decorator against the call sites above. None of these are dead code — checked against `scripts/`, `backend/scripts/`, and `ARCHITECTURE.md`, and all are accounted for as manual/admin/dev tooling that's out-of-band from the frontend by design:

- `POST /api/scenarios/generate` — called from `backend/scripts/verify-extraction.ts` and `backend/scripts/verify-replay.ts` (dev verification scripts). The frontend uses `/api/tutor/generate-scenario` instead.
- `POST /api/knowledge-units/bulk`, `PATCH /api/knowledge-units/bulk` — added in commit `f26e781` alongside `backend/scripts/get-token.mjs`, which mints a Firebase ID token for manual `curl` calls against admin-guarded routes. No committed script calls `bulk` itself — it's invoked ad hoc from the terminal.
- `POST /api/knowledge-units/migrate/grammar-jlpt-level` — `AdminGuard`-protected one-off migration, already run and documented in `ARCHITECTURE.md:729` ("333 records migrated; 18 without any level skipped").
- `POST /api/knowledge-units/migrate/grammar-corpus-notes` — sibling `AdminGuard`-protected one-off migration, same pattern, undocumented in ARCHITECTURE.md.
- `GET /api/auth/test` — trivial "is my token valid" smoke-test route (`FirebaseAuthGuard`-only, returns `{message, uid}`) for manually debugging auth issues.
- `GET /` (`app.controller.ts` root) — plain health-check route; no caller found anywhere, likely just infra/uptime-check surface.
